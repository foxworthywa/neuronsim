# PEDAGOGY.md — principles for every scene

1. **Prediction before explanation.** The student predicts what an ion or a voltage will do
   before the simulation shows it. Only then do we animate.
2. **Causal reasoning over terminology recall.** Questions ask "which way / what happens / why",
   not "what is this called". Names are introduced after the function is understood.
3. **Visual effects must correspond to simulated state.** Nothing on screen is a canned
   animation. Ions move because a current is flowing in the model; a channel is drawn open
   because its gating variables say so; the trace is the model's voltage.
4. **Never advance merely because time elapsed.** Continue is enabled only when the question
   is answered correctly and the activity (fire, hold, wait for a spike) is done.
5. **Misconceptions receive targeted feedback.** Every wrong option has its own explanation that
   addresses that specific misconception, and the student can try again.
6. **Minimize text walls.** Short paragraphs; one idea per step; the picture carries the meaning.
7. **Connect microscopic events to whole-cell consequences.** Every zoomed view keeps a
   whole-neuron inset and the live voltage trace; the same trace persists from the electrode
   scene onward.
8. **One continuous causal journey.** receive → integrate → decide → propagate → transmit →
   the next neuron receives. The action potential is taught once, built from channel behaviour,
   not first as a curve and then again microscopically.
9. **Semi-quantitative model, invisible equations.** The student never sees Hodgkin–Huxley,
   but the behaviour is right, so free play (block Na⁺ channels, raise K⁺, switch off the pump)
   produces real consequences rather than another canned animation.
