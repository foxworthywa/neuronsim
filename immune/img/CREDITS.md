- **Title:** Anatomy of the Lymphatic System
- **Author:** OpenStax College
- **Source:** *Anatomy & Physiology*, Connexions Web site, http://cnx.org/content/col11496/1.6/,
  19 June 2013; file obtained from Wikimedia Commons,
  https://commons.wikimedia.org/wiki/File:2201_Anatomy_of_the_Lymphatic_System.jpg
- **Licence:** Creative Commons Attribution 3.0 Unported (CC BY 3.0),
  https://creativecommons.org/licenses/by/3.0/
- **Changes:** recompressed as a JPEG; not cropped, relabelled or otherwise altered.
- **Where it is used:** scene 1 of ImmuneSim, beside the lab's own diagram of the body, and in the
  "larger view" window. `immune/anatomy.js` is the same image as a data URI, generated by
  `node immune/img/embed.js`.

A note on the choice of copy: the same figure appears in the current OpenStax book on
openstax.org (Figure 21.2), where OpenStax now licenses its images CC BY-NC-SA 4.0. The 2013
release on Wikimedia Commons carries the more permissive CC BY 3.0, which cannot be withdrawn, so
that copy is used here. If the sim is ever used commercially, this is the copy that allows it.
