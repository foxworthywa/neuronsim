`kidney/anatomy.js` holds both images as data URIs, generated by `node kidney/img/embed.js`.

A note on the choice of copy, as for ImmuneSim: the same figures appear in the current OpenStax
book on openstax.org, where OpenStax now licenses its images CC BY-NC-SA 4.0. The 2013 release on
Wikimedia Commons carries the more permissive CC BY 3.0, which cannot be withdrawn, so those
copies are used here. The licence shown on each Commons file page was checked on 24 November 2026.
